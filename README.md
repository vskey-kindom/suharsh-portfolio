# Suharsh's Portfolio

A responsive personal portfolio built with React, Vite, Framer Motion and Lucide icons. The visual direction is editorial and cinematic: near-black surfaces, warm white typography, and a restrained wine-red accent.

## Run locally

1. Install Node.js (LTS recommended).
2. Open this folder in VS Code or a terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

The production files are generated in `dist/`.

## Update your details

Edit `src/data/content.js` to update your bio, projects, skills, social links, and contact details. The page title and search description are in `index.html`.

## Notes

- The portfolio describes VSKEY as a B2B trade brokerage concept, not as an established marketplace.
- Tuesday / ACE is presented as a personal desktop AI assistant experiment.
- Project descriptions are intentionally limited to work and experience supplied by Suharsh.
- The custom cursor only appears on devices that support a fine pointer; touch devices use the normal browser interaction.
